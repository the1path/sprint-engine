## Implementation and contracts

Only `templates/dashboard.php` changes runtime behavior:

- `sprint_engine/dashboard_before_sprint_sections( $context )` runs once inside
  the existing main landmark before individual Sprint sections, including when
  Core has zero items. The sole argument is the unchanged authorized ready context.
- `sprint_engine/dashboard_has_additional_sections( false, $context )` runs once
  after that action. Only exact boolean `true` suppresses the original empty-state
  message when all Core sections are empty. False, null, integer/string truthy
  values, nonempty arrays and objects retain it. Populated Core sections always
  render. Rendering and the signal should share request-local authorized data.
- `sprint_engine/dashboard_card_context( $item, $state )` runs once per rendered
  individual Sprint card, immediately after `<h3>` and before excerpt/description,
  in existing section/card order. Arguments are exactly the existing safe item
  and canonical `in_progress`, `not_started` or `completed` display state.

All three require an authenticated `ready` render. Error/login, partial error
contexts and anonymous stale ready contexts cannot trigger them. Unavailable,
unpublished or access-denied cards never reach the card hook. No instructional
Step content, additional user identity or History record is supplied.

There is no new wrapper, default content, CSS/JS, query, context field, option,
cache, table, authorization/progress decision or Journey logic. The coordinator,
`dashboard_items` filter and template-selection contract are unchanged. Installed
trusted callbacks own their data lookup, ownership/access, escaped accessible
markup, destination authorization and scoped styling; Core cannot sandbox PHP.

The existing header action stays after the intro in the header. Existing
completed-card recommendations stay after Restart/View controls. Titles, images,
descriptions, progress, canonical URLs, order, branding, main/skip link, one `<h1>`,
private/no-store/noindex and nonce handling remain intact. No listeners preserve
default visible output. Template overrides remain responsible for hook placement.

## Illustrative trusted consumer (documentation only)

This synthetic example uses no Journey storage or business logic. It links back
to My Sprints and attaches example context to one already-authorized Sprint.
Replace the demo model with an independently authorized, read-only extension lookup;
never infer ownership from these example labels or from the boolean signal.
The same request-local model drives section rendering, empty-state coordination
and optional card context. No persistent cache or progress write is needed.

```php
$example_dashboard = array();

add_filter( 'sprint_engine/dashboard_template', static function ( $path, $context ) use ( &$example_dashboard ) {
    $example_dashboard = array();
    if ( is_user_logged_in() && 'ready' === ( $context['state'] ?? '' ) ) {
        $items = array_merge( ...array_values( $context['sections'] ) );
        $example_dashboard = array(
            'title'      => 'Example learning path',
            'url'        => \ThePath\SprintEngine\Dashboard\Routes::url(),
            'sprint_ids' => array_slice( array_column( $items, 'sprint_id' ), 0, 1 ),
        );
    }
    return $path; // Observe the resolved context; retain Core's template.
}, 20, 2 );

add_action( 'sprint_engine/dashboard_before_sprint_sections', static function ( $context ) use ( &$example_dashboard ) {
    if ( ! $example_dashboard ) {
        return;
    }
    echo '<section aria-labelledby="example-paths"><h2 id="example-paths">Example paths</h2><a href="'
        . esc_url( $example_dashboard['url'] ) . '">'
        . esc_html( $example_dashboard['title'] ) . '</a></section>';
} );

add_filter( 'sprint_engine/dashboard_has_additional_sections', static function ( $has_sections, $context ) use ( &$example_dashboard ) {
    return true === $has_sections || ! empty( $example_dashboard );
}, 10, 2 );

add_action( 'sprint_engine/dashboard_card_context', static function ( $item, $state ) use ( &$example_dashboard ) {
    if ( $example_dashboard && in_array( $item['sprint_id'], $example_dashboard['sprint_ids'], true ) ) {
        echo '<p><a href="' . esc_url( $example_dashboard['url'] ) . '">'
            . esc_html( $example_dashboard['title'] ) . '</a></p>';
    }
}, 10, 2 );
```
