# SE-025 — Back to Website Navigation

## Implementation and display rules

The built-in Runner links the organisation logo to the WordPress homepage
when the branding helper returns an image. The link uses the accessible name
“Go to website homepage”; the image markup and size constraints are unchanged.
The link wrapper takes over the logo's automatic flex margin to preserve header
alignment and wrapping. No image means no logo link or placeholder.

A centred, underlined **Back to website** link with a decorative arrow follows
`main`, outside the authored content, Sprint actions and completion hooks. It
uses the Runner's muted text colour on the page background and inherits the
configured typeface. Both links use the Runner's existing keyboard focus styles
and navigate in the same tab to escaped `home_url( '/' )`.

The footer appears on Welcome, active Step, completion, generic error and
access-denied pages, including the opt-in anonymous gateway. It does not depend
on a logo. Login redirects render no Runner markup. Administrator Step Preview
retains its unlinked logo, with no website footer or participant controls. The
branding settings preview and Dashboard logos remain unlinked. Replacement
templates supplied through `sprint_engine/runner_template` own their markup.

Core adds no JavaScript, progress or Workspace writes, prompts, or access rules.
Opening an active Runner still performs the existing resume bookkeeping.
The links do not save Workspace drafts. When Pro is installed, its existing
unsaved Workspace warning still applies to leaving a page with a dirty answer.

packaged plugin ran on WordPress 7.1.2/PHP 8.3.35 with SQLite and on the minimum
WordPress 6.0/PHP 8.0.30 combination with MariaDB 10.11.11. Core was tested on
its own; the modern site was also tested with unchanged Pro 0.1.0.

A focused Chromium check used a WordPress site with a different `home` and
`siteurl`, with the homepage at `/participant-site/`. Both links reached that
homepage in the same tab on both runtimes. At 1440, 768, 390 and 320 px the
image and header controls matched their positions and sizes with the original
unlinked logo. The underlined footer stayed centred and met 4.5:1 text contrast
in both tested palettes. Both links had visible focus and worked with Enter.
Comparing database rows immediately before activation and after the destination
loaded showed identical attempt, Step progress, and (with Pro) Workspace rows,
including timestamps. Leaving sent no write request, even after editing a
Workspace response without saving it.
