# Security reporting

Please do **not** post potential security vulnerabilities as public GitHub issues
or include exploit details in public pull requests.

Use this repository's **Security → Report a vulnerability** option when GitHub
private vulnerability reporting is enabled. If that option is unavailable, use
an available private security reporting channel listed by the repository owner.
If none is listed, ask the owner to provide one without disclosing vulnerability
details publicly.

Include the affected plugin version, reproduction steps and potential impact in
the private report. Remove credentials and unrelated personal data.
